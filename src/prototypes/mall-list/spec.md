# 商城清单

## 📋 业务与功能

### 1.1 核心目标
展示低空相关产品和服务商城，支持分类浏览、搜索、查看详情、提交采购意向。

### 1.2 功能清单
- **商品分类**：按产品类型分类浏览
- **商品搜索**：关键词搜索商品
- **商品列表**：卡片式展示商品信息
- **商品详情**：点击查看详细信息
- **采购意向**：跳转提交采购意向

### 1.3 交互要点
- 点击商品卡片 → 查看商品详情
- 点击「提交采购意向」→ 跳转采购意向页
- 切换分类 → 筛选对应类型商品
