# 后台系统用户管理

## 📋 业务与功能

### 1.1 核心目标
用于超级管理员或人事部门管理系统内部的运营人员账号，支持为其开通后台账号并分配相应的管理角色权限。

### 1.2 功能清单
- **数据列表**：账号名、真实姓名、联系电话、所属部门、系统角色（超级管理员、内容运营、审核员等）、状态、创建时间。
- **快速筛选**：按系统角色、部门、状态筛选，按真实姓名/账号检索。
- **新增运营人员**：弹窗表单（账号、初始密码、姓名、联系电话、所属部门、系统角色）。
- **编辑人员**：修改除账号外的其他信息（姓名、部门、角色、状态等）。
- **重置密码**：重置运营人员的后台登录密码。
- **禁用/启用**：管控员工离职或调岗时的账号权限。

### 1.3 交互要点
- 点击「新增账号」→ 弹出新增表单，密码默认提供随机强密码或指定默认密码。
- 点击「编辑」→ 弹出包含已有数据的编辑表单。
- 状态切换时提供二次确认提示。
