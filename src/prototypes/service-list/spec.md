# 低空服务与需求大厅

## 📋 业务与功能

### 1.1 核心目标
展示平台提供的低空服务清单和用户发布的服务需求，支持分类浏览、搜索和发布。

### 1.2 功能清单
- **Tab 切换**：服务大厅 / 需求大厅 双Tab切换
- **服务分类**：按服务类型分类浏览（行业应用、航拍影像、飞行培训、低空旅游、飞行器服务）
- **需求分类**：按需求类型分类浏览（航拍摄影、巡检服务、飞行培训、物流配送、其他需求）
- **搜索**：关键词搜索服务/需求
- **服务列表**：卡片式展示服务信息（渐变封面+图标+价格+分类标签+服务商）
- **需求列表**：卡片式展示需求信息（渐变顶部条+标题+状态+预算+区域+发布人+截止日期）
- **发布入口**：
  - 服务大厅 → 我要发布服务（绿色按钮）→ 跳转 service-publish
  - 需求大厅 → 我要发布需求（橙色按钮）→ 跳转 demand-publish

### 1.3 交互要点
- 切换Tab → 标题/副标题/搜索框/发布按钮随之变化
- 点击服务卡片 → service-detail
- 切换分类 → 筛选对应类型
- 搜索 → 实时过滤
