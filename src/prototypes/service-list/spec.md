# 服务清单

## 📋 业务与功能

### 1.1 核心目标
展示平台提供的低空服务清单，支持分类浏览、搜索和需求提交。

### 1.2 功能清单
- **服务分类**：按服务类型分类浏览
- **服务搜索**：关键词搜索服务
- **服务列表**：卡片式展示服务信息
- **服务详情**：点击查看服务详情
- **提交需求**：跳转提交服务需求页

### 1.3 交互要点
- 点击服务卡片 → 查看服务详情
- 点击「提交需求」→ 跳转服务需求页
- 切换分类 → 筛选对应类型服务
