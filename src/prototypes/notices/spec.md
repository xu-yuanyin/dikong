# 通知公告

## 📋 业务与功能

### 1.1 核心目标
为用户提供低空飞行服务相关的通知公告查看入口，集中展示政策法规、通知公告、行业动态等信息，支持分类筛选、关键词搜索和详情查看。

### 1.2 功能清单
- **公告列表展示**：展示所有通知公告，包含标题、类型、发布时间、紧急程度等
- **类型筛选**：支持按公告类型筛选（全部、政策法规、通知公告、行业动态）
- **关键词搜索**：支持按标题关键词搜索
- **紧急标识**：紧急公告显示醒目标识
- **详情查看**：点击公告查看详细内容

### 1.3 交互要点
- Tab 切换：点击类型 Tab 快速筛选
- 搜索框：输入关键词实时搜索
- 列表项点击：展开公告详情
- 紧急公告：红色标签醒目提示

## 📊 内容规划

### 2.1 信息架构
```
通知公告
├── 筛选操作区
│   ├── 类型 Tab 筛选
│   └── 关键词搜索框
├── 公告列表区
│   ├── 紧急标识
│   ├── 公告标题
│   ├── 公告类型
│   ├── 发布时间
│   └── 操作按钮
└── 分页区
```

### 2.2 数据来源
- **数据类型**：公告列表
- **数据源**：生成示例数据
- **关键字段**：
  - `id`: 公告唯一标识
  - `title`: 公告标题
  - `type`: 公告类型（policy/notice/dynamic）
  - `urgent`: 是否紧急
  - `publishTime`: 发布时间
  - `content`: 公告内容摘要

### 2.3 内容示例
**公告类型映射**：
- `policy`: 政策法规
- `notice`: 通知公告
- `dynamic`: 行业动态

## 🎨 布局与结构

### 3.1 整体布局
- **布局模式**：左侧导航 + 右侧内容区（与服务概览页面保持一致）
- **容器宽度**：最大 1200px
- **关键尺寸**：
  - 左侧导航：宽度 220px
  - 列表项：高度自适应

### 3.2 响应式适配
- **桌面端（≥1200px）**：左侧导航 + 右侧内容
- **平板端（768-1199px）**：顶部导航 + 内容区
- **移动端（<768px）**：单栏布局
