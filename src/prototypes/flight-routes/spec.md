# 航路航线

## 📋 业务与功能

### 1.1 核心目标
展示区域内已规划的航路航线信息，包括航线距离、高度范围、使用状态等，为飞行计划制定提供参考。

### 1.2 功能清单
- **航线列表展示**：展示所有航路航线，包含编号、名称、距离、高度、状态等
- **状态筛选**：支持按航线状态筛选（可用、限制）
- **关键词搜索**：支持按航线名称搜索
- **详情查看**：点击查看航线详细信息
