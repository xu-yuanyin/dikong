# 低空应急服务

## 📋 业务与功能

### 1.1 核心目标
提供一键报警、救援调度、预警发布、数据留存等应急服务，保障低空飞行安全。

### 1.2 功能清单
- **一键报警**：位置上报、轨迹追踪、信息上传
- **救援调度**：联动应急、公安、消防等部门
- **预警发布**：应急预警、处置进展、安全提醒
- **数据留存**：飞行轨迹、数据记录、事故调查
