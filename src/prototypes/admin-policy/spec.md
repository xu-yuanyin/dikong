# 政策管理

## 📋 业务与功能

### 1.1 核心目标
后台管理端的政策法规维护页面，支持国家政策、本地政策、政策解读三类内容的全生命周期管理。

### 1.2 功能清单
- **Tab切换**：国家政策管理 / 本地政策管理 / 政策解读管理
- **搜索筛选**：标题搜索、分类/类型筛选、效力状态筛选、发布状态筛选、查询/重置按钮
- **操作按钮（按状态区分）**：
  - 草稿：查看、编辑、发布、删除
  - 已发布：查看、撤回
- **新建弹窗**：政策标题、分类（必选）、发布单位（必填）、文号（必填）、效力状态（必选：现行有效/已修订/已废止/待生效）、摘要、正文（富文本）、底部按钮（取消/保存草稿/预览/立即发布）
- **查看弹窗**：Descriptions 展示完整数据，底部关闭+预览按钮
- **操作栏**：icon 按钮 + Tooltip 悬停提示

### 1.3 交互要点
- 点击「查看」→ 打开查看弹窗
- 点击「预览」→ 跳转前台对应页面
- 点击「发布/删除/撤回」→ 确认弹窗
