# 资讯公告

## 📋 业务与功能

### 1.1 核心目标
展示低空领域新闻资讯和通知公告，支持分类筛选和搜索，帮助用户快速获取行业动态与平台通知。

### 1.2 功能清单
- **Tab 切换**：新闻资讯 / 通知公告
- **新闻资讯**：搜索标题、分类筛选（全部、行业新闻、技术前沿、培训认证、安全提示）、卡片式列表、分页
- **通知公告**：搜索标题、类型筛选（全部、空域通知、气象预警、活动通知、系统公告、维护通知）、卡片式列表（含置顶标签）、分页
- **点击卡片** → 跳转对应详情页

### 1.3 交互要点
- 点击分类标签 → 筛选对应类别
- 输入搜索词 → 实时过滤
- 点击新闻卡片 → 跳转 news-detail
- 点击公告卡片 → 跳转 notice-detail
- 点击首页 → 跳转首页


## 🔌 Axure API

### 5.1 事件列表（eventList）

| name | desc | payload |
|------|------|---------|
| `on_tab_change` | Tab 切换时触发，传递当前 tab 标识 | `news \| notice` |
| `on_news_click` | 点击新闻卡片时触发，传递新闻 ID | `string` |
| `on_notice_click` | 点击公告卡片时触发，传递公告 ID | `string` |
| `on_search` | 搜索时触发，传递当前搜索词和 tab | `JSON string` |

### 5.2 动作列表（actionList）

| name | desc | params |
|------|------|--------|
| `switch_tab` | 切换 Tab，参数：news 或 notice | `string` |
| `set_news_category` | 设置新闻分类筛选，参数：分类名称 | `string` |
| `set_notice_type` | 设置公告类型筛选，参数：类型 key | `string` |
| `set_search_text` | 设置搜索关键词 | `JSON string {"tab":"news\|notice","text":"关键词"}` |
| `reset_filter` | 重置所有筛选条件 | — |

### 5.3 变量列表（varList）

| name | desc |
|------|------|
| `active_tab` | 当前激活的 Tab（news / notice） |
| `news_category` | 当前新闻分类筛选值 |
| `notice_type` | 当前公告类型筛选值 |
| `news_search_text` | 当前新闻搜索关键词 |
| `notice_search_text` | 当前公告搜索关键词 |
| `filtered_news_count` | 筛选后的新闻数量 |
| `filtered_notice_count` | 筛选后的公告数量 |

### 5.4 配置项列表（configList）

无配置项（空列表）。

### 5.5 数据项列表（dataList）

**news_list** — 新闻资讯列表数据

| name | desc |
|------|------|
| `id` | 新闻唯一标识（数字） |
| `title` | 新闻标题（字符串） |
| `date` | 发布日期（字符串，YYYY-MM-DD） |
| `category` | 新闻分类（字符串） |
| `views` | 浏览量（数字） |
| `summary` | 新闻摘要（字符串） |

**notice_list** — 通知公告列表数据

| name | desc |
|------|------|
| `id` | 公告唯一标识（数字） |
| `title` | 公告标题（字符串） |
| `type` | 公告类型 key（字符串） |
| `typeLabel` | 公告类型显示名称（字符串） |
| `typeColor` | 类型标签颜色（字符串，十六进制色值） |
| `publishDate` | 发布日期（字符串，YYYY-MM-DD） |
| `effectiveDate` | 有效期（字符串） |
| `isTop` | 是否置顶（布尔值） |
| `content` | 公告正文内容（字符串） |
