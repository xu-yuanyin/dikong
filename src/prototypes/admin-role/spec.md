# 角色管理

## 📋 业务与功能

### 1.1 核心目标
后台管理端的角色管理页面，支持查看、新增、编辑、删除系统角色，配置角色的权限项。

### 1.2 功能清单
- **搜索筛选**：角色名称搜索、状态筛选
- **数据列表**：角色名称、角色标识、描述、用户数、状态、创建时间
- **新增角色**：弹窗表单（角色名称、角色标识、描述、权限配置树）
- **编辑角色**：弹窗表窗（可修改名称、描述、权限）
- **查看角色**：Descriptions 详情弹窗含权限列表
- **删除角色**：确认弹窗（系统内置角色不可删除）
- **权限配置**：树形多选（模块级 + 操作级）

### 1.3 交互要点
- 点击「新增角色」→ 打开新增弹窗
- 点击「编辑」→ 打开编辑弹窗
- 点击「查看」→ 打开详情弹窗
- 点击「删除」→ 确认弹窗 → 删除成功提示
- 点击「禁用/启用」→ 确认弹窗 → 状态切换
