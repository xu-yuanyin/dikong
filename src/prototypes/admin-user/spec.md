# 门户用户管理

## 📋 业务与功能

### 1.1 核心目标
后台管理端用于管理“前台门户”注册的用户，运营人员可查看用户的基本信息、审核其提交的认证资质，以及对违规账号进行状态管控。

### 1.2 功能清单
- **高级搜索筛选**：通过手机号搜索，按角色（个人/飞手/企业/服务商/商户/政府）、认证状态（未认证/审核中/已认证）、账号状态（正常/已禁用）进行筛选。
- **数据列表**：展示用户名、手机号、已认证角色、认证状态、注册时间、最后登录时间、账号状态。
- **查看用户**：弹窗展示用户详细信息，包含基础信息与实名认证资料。
- **禁用/启用**：二次确认弹窗 → 状态切换（管控违规账号）。
- **重置密码**：协助用户重置为默认密码。
- **说明**：该页面不提供手动“新增”与随意修改用户资料的功能，侧重于管控与审查。

### 1.3 交互要点
- 点击「查看」→ 打开详情抽屉或弹窗，展示用户的基础资料与认证记录。
- 点击「禁用/启用」→ 确认弹窗 → 状态切换并显示成功提示。
- 点击「重置密码」→ 确认弹窗 → 提示重置后的默认密码。
