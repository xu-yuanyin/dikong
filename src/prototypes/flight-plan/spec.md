# 提交飞行计划

## 📋 业务与功能

### 1.1 核心目标
为飞手和企业提供飞行计划在线提交功能，填写飞行任务信息并提交审核。

### 1.2 功能清单
- **飞行计划表单**：飞行任务名称、飞行器选择、起飞/降落地点、飞行时间、飞行高度、任务描述
- **地图选点**：可视化选择起降地点
- **附件上传**：上传飞行相关文件
- **提交审核**：提交飞行计划等待审批

### 1.3 交互要点
- 填写表单 → 提交审核 → 提示提交成功
- 点击地图选点 → 标记起降位置
