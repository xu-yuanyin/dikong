# 空域划设

## 📋 业务与功能

### 1.1 核心目标
展示区域内所有已划设的空域信息，包括管制空域和非管制空域的详细参数、使用规则和申请流程。

### 1.2 功能清单
- **空域列表展示**：展示所有已划设空域，包含编号、名称、类型、高度范围、面积等
- **类型筛选**：支持按空域类型筛选（管制空域、非管制空域）
- **关键词搜索**：支持按空域名称或编号搜索
- **详情查看**：点击查看空域详细信息

### 1.3 交互要点
- Tab 切换：点击类型 Tab 快速筛选
- 搜索框：输入关键词实时搜索
- 列表项点击：查看空域详情
