# 我的飞行器

## 📋 业务与功能

### 1.1 核心目标
用户个人中心-我的飞行器管理，查看已注册飞行器列表，支持新增、编辑、删除。

### 1.2 功能清单
- **飞行器列表**：展示用户名下所有飞行器
- **新增飞行器**：添加新的飞行器信息
- **编辑飞行器**：修改飞行器信息
- **删除飞行器**：删除飞行器记录

### 1.3 交互要点
- 点击「新增」→ 打开新增弹窗
- 点击「编辑」→ 打开编辑弹窗
- 点击「删除」→ 确认弹窗 → 删除成功
