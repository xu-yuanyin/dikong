# 资讯公告管理

## 📋 业务与功能

### 1.1 核心目标
后台管理端的资讯公告维护页面，支持新闻资讯和通知公告的新建、编辑、发布、撤回、删除等全生命周期管理。

### 1.2 功能清单
- **Tab切换**：新闻资讯管理 / 通知公告管理
- **新闻资讯管理**：搜索标题、分类筛选、状态筛选、查询/重置按钮、新建新闻、数据列表
- **通知公告管理**：搜索标题、类型筛选、状态筛选、查询/重置按钮、新建公告、数据列表
- **操作按钮（按状态区分）**：
  - 草稿：查看、编辑、发布、删除
  - 已发布：查看、撤回
- **新建新闻弹窗**：标题、分类、作者、来源（必填）、摘要、正文（富文本编辑器）、底部按钮（取消/保存草稿/预览/立即发布）
- **新建公告弹窗**：标题、类型、发布单位、有效期、置顶开关、正文、底部按钮
- **查看弹窗**：Descriptions 组件展示完整数据详情
- **操作栏**：icon 按钮展示，鼠标悬停 Tooltip 显示名称

### 1.3 交互要点
- 点击「查看」→ 打开查看弹窗（非跳转）
- 点击「发布」→ 确认弹窗 → 发布成功提示
- 点击「撤回」→ 确认弹窗 → 撤回成功提示
- 点击「删除」→ 确认弹窗 → 删除成功提示
- 点击「新建」→ 打开新建弹窗
- 点击「预览」→ 跳转前台详情页
