# 规范标准详情

## 📋 业务与功能

### 1.1 核心目标
门户规范标准的详情查看页，展示标准的完整信息、正文内容和相关附件。

### 1.2 功能清单
- **基本信息**：标准名称、编号、类型、发布机构、发布/实施日期、状态
- **正文内容**：标准正文分段展示
- **附件下载**：相关文件下载入口
- **字号调节**：小/中/大切换
- **返回列表**：返回规范标准列表

### 1.3 交互要点
- 点击返回 → 跳转 standard-list
- 字号切换实时生效
- 附件点击下载提示
- 顶部导航栏各模块跳转
