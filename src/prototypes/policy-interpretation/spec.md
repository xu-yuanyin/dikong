# 政策解读

## 📋 业务与功能

### 1.1 核心目标
展示政策解读信息，支持按解读类型分类浏览和搜索。

### 1.2 功能清单
- **Hero Banner 检索区**：图标 + 标题 + 副标题 + 大搜索框（maxWidth 480, height 44, size large），蓝色渐变背景
- **Tab 导航**：国家政策 / 本地政策 / 政策解读，切换跳转
- **药丸式筛选**：全部 / 图文解读 / 权威解读 / 专家解读 / 视频解读 / 政策问答，选中态蓝色填充
- **解读列表**：卡片式展示，含类型图标、类型标签、标题、摘要、日期、来源、关联政策
- **搜索功能**：支持标题和内容搜索
- **空状态**：无匹配结果时显示提示
- **分页**

### 1.3 交互要点
- 点击解读条目 → 查看解读详情
- 切换解读类型筛选 → 筛选对应类型解读
- 搜索 → 按关键词筛选
- Tab 切换 → 跳转对应页面
