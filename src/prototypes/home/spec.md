# 首页

## 📋 业务与功能

### 1.1 核心目标
作为低空公共服务管理系统的门户首页，承载信息展示与导航引导功能，让政府部门、企业、飞手、公众快速了解平台能力并进入对应服务。

### 1.2 功能清单
- **顶部导航栏**：Logo、主导航菜单（首页、新闻资讯、政策法规、低空服务、低空商城、飞行服务）、个人中心（始终显示）、登录/注册入口（未登录时显示）/ 用户头像下拉（已登录时显示）
- **Hero Banner**：平台品牌展示、核心价值主张
- **飞行业务流程**（仅登录后显示）：三步流程引导（飞行主体审批 → 飞行器备案 → 飞行计划备案），跳级操作弹出提示
- **低空服务大厅**：六大服务模块卡片（低空旅游、飞行培训、资质查询、飞行器服务、低空科普、意见反馈）
- **新闻动态**：最新3条新闻资讯预览
- **政策速递**：最新2条政策法规预览
- **低空商城**：精选商品展示（4件商品卡片，含标签、价格、评分）
- **数据概览**：平台运营数据展示（注册用户数、飞行计划数、服务企业数、空域覆盖率）
- **底部信息**：平台介绍、快速链接、联系方式

### 1.3 交互要点
- 点击导航菜单项 → 跳转对应页面
- 点击个人中心 → 跳转个人中心（未认证）页面
- 点击登录/注册 → 模拟登录状态切换
- 已登录时点击用户头像 → 下拉菜单（个人信息、退出登录）
- 退出登录 → 回到未登录状态，飞行业务流程模块隐藏
- 点击飞行业务流程步骤1（飞行主体审批）→ 跳转个人中心认证页
- 点击飞行业务流程步骤2（飞行器备案）→ 弹出提示"请先完成飞行主体审批"
- 点击飞行业务流程步骤3（飞行计划备案）→ 弹出提示"请先完成飞行主体审批和飞行器备案"
- 点击低空服务大厅卡片 → 跳转服务大厅页
- 点击低空商城商品卡片 → 跳转商品详情页
- 点击新闻/政策卡片 → 跳转对应列表页

## 📊 内容规划

```
首页
├── 顶部导航栏
│   ├── Logo + 平台名称

│   └── 登录/注册按钮（未登录） / 用户头像下拉（已登录）
├── Hero Banner
│   ├── 品牌标语
│   └── 副标题描述
├── 飞行业务流程（仅登录后显示）
│   ├── STEP 1: 飞行主体审批
│   ├── → 箭头
│   ├── STEP 2: 飞行器备案
│   ├── → 箭头
│   └── STEP 3: 飞行计划备案
├── 低空服务大厅（3×2 网格）
│   ├── 低空旅游
│   ├── 飞行培训
│   ├── 资质查询
│   ├── 飞行器服务
│   ├── 低空科普
│   └── 意见反馈
├── 新闻动态 + 政策速递（左右双栏 14:10）
├── 低空商城（4列商品卡片）
├── 数据概览（4列等宽）
└── 底部信息
    ├── 平台介绍
    ├── 快速链接
    └── 联系我们
```

### 2.2 数据来源
- **数据类型**：展示型数据
- **数据源**：生成示例数据
- **关键字段**：
  - `service_modules`: 服务模块列表（key, icon, title, color, bg, desc）
  - `mall_products`: 商品列表（id, name, price, rating, desc, tag）
  - `news`: 新闻列表（title, date, tag）
  - `policies`: 政策列表（title, date, type）
  - `stats`: 统计数据（label, value, unit）

## 🎨 布局与结构

### 3.1 整体布局
- **布局模式**：单栏流式布局
- **容器宽度**：最大1200px居中
- **关键尺寸**：
  - Hero Banner：全宽，高度自适应
  - 飞行业务流程：3列等宽 + 箭头连接，卡片宽度280px
  - 低空服务大厅：3×2 网格，卡片横向布局（图标+文字）
  - 新闻/政策区：左右双栏（14:10比例）
  - 低空商城：4列商品卡片
  - 数据概览：4列等宽网格

### 3.2 响应式适配
- **桌面端（≥1200px）**：完整3列流程 + 3×2服务网格 + 双栏内容 + 4列商城
- **平板端（768-1199px）**：流程卡片缩小，服务网格2列
- **移动端（<768px）**：单列堆叠

## ⚙️ Axure API 说明

### 5.1 事件列表（eventList）
| 事件名称 | Payload 类型 | 触发时机 | 说明 |
|---------|-------------|---------|------|
| `navigate` | `string` | 点击导航/卡片 | 页面跳转，payload为目标页面标识 |
| `flow_warning` | `string` | 跳级点击流程步骤 | 弹出流程提示，payload为提示信息 |
| `login` | `void` | 点击登录/注册 | 模拟登录状态切换 |
| `logout` | `void` | 点击退出登录 | 回到未登录状态 |

### 5.2 变量列表（varList）
| 变量名称 | 类型 | 默认值 | 说明 |
|---------|-----|-------|------|
| `is_logged_in` | `boolean` | `false` | 用户是否已登录 |
| `subject_approved` | `boolean` | `false` | 飞行主体是否已审批 |
| `aircraft_filed` | `boolean` | `false` | 飞行器是否已备案 |
