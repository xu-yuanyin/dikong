# 备案飞行计划

## 📋 业务与功能

### 1.1 核心目标
提供飞行计划在线备案功能，飞手和企业可提交飞行计划进行备案登记。

### 1.2 功能清单
- **备案表单**：飞行计划名称、飞行器选择、飞行时间、飞行区域、飞行高度、任务描述
- **地图标注**：在地图上标注飞行路线
- **材料上传**：上传飞行计划相关文件
- **提交备案**：提交备案申请等待审核

### 1.3 交互要点
- 填写表单 → 提交备案 → 提示提交成功
- 地图标注 → 标记飞行路线
- 上传材料 → 文件上传成功提示
