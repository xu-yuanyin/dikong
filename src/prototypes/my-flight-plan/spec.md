# 我的飞行计划

## 📋 业务与功能

### 1.1 核心目标
用户个人中心-我的飞行计划管理，查看已提交的飞行计划及审批状态。

### 1.2 功能清单
- **飞行计划列表**：展示用户所有飞行计划
- **审批状态**：待审核、已通过、已驳回、已取消
- **计划详情**：查看飞行计划详细信息
- **新增计划**：跳转提交飞行计划页

### 1.3 交互要点
- 点击飞行计划 → 查看计划详情
- 点击「提交计划」→ 跳转飞行计划页
