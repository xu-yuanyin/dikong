# 我的信息

## 📋 业务与功能

### 1.1 核心目标
用户个人中心首页，展示用户基本信息、账户安全状态和快捷功能入口，管理个人账户。

### 1.2 功能清单
- **个人信息展示与修改**：头像、姓名、角色、联系方式。支持在左侧头像区或卡片区一键触发“修改个人信息”。
- **账号安全设置**：
  - **登录密码**：展示密码安全等级，支持弹出修改密码对话框进行修改。
  - **绑定手机**：展示已绑定的安全手机，支持弹出对话框输入验证码更换手机号。
  - **安全邮箱**：展示已绑定的邮箱，支持弹出对话框更换邮箱地址。
- **快捷入口**：我的飞行器、我的飞行计划、我的服务、我的预约。
- **侧边导航**：个人中心各子页面导航。

### 1.3 交互要点
- 点击「编辑信息」或左侧快捷链接 → 进入基本信息编辑模式并平滑滚动到视图中。
- 点击「修改密码」 → 弹出修改密码 Modal：
  - 动态监测新密码强度，弱/中/强以不同颜色进度条形式展示。
  - 校验两次新密码输入是否一致。
  - 模拟提交成功并给出清晰提示。
- 点击「更换手机」/「更换邮箱」 → 弹出验证 Modal，支持点击“获取验证码”并进行验证模拟。

## 📊 内容规划

### 2.1 信息架构
```
我的信息
├── 侧边导航
│   ├── 我的信息
│   ├── 我的飞行器
│   ├── 我的飞行计划
│   ├── 我的服务
│   └── 我的预约
├── 个人信息卡片
│   ├── 头像与角色标签
│   └── 快捷入口（修改个人资料 / 修改密码）
├── 基本信息区域
│   ├── 昵称、角色类型、联系方式、所属单位、注册时间、状态
│   └── 修改信息操作入口
├── 账号安全设置区域
│   ├── 登录密码（已设置，建议定期更换） -> [修改密码]
│   ├── 绑定手机（138****8888） -> [更换手机]
│   └── 安全邮箱（zhangming@example.com） -> [更换邮箱]
└── 认证信息区域
    └── 状态信息、认证材料提交入口
```
