# 我的信息

## 📋 业务与功能

### 1.1 核心目标
用户个人中心首页，展示用户基本信息和快捷功能入口，管理个人账户。

### 1.2 功能清单
- **个人信息展示**：头像、姓名、角色、联系方式
- **信息编辑**：修改个人基本信息
- **快捷入口**：我的飞行器、我的飞行计划、我的需求、我的订单
- **侧边导航**：个人中心各子页面导航

### 1.3 交互要点
- 点击「编辑」→ 进入编辑模式
- 点击快捷入口 → 跳转对应子页面
- 点击侧边导航 → 切换子页面
