# 低空便民服务

## 📋 业务与功能

### 1.1 核心目标
门户低空便民服务综合展示页，汇聚 6 大服务模块，为公众提供一站式低空服务入口。

### 1.2 六大服务模块
1. **低空旅游** — 线路·产品·票价·预约·支付·评价
2. **飞行培训** — 正规培训机构·课程·费用·报名·考核
3. **资质查询** — 飞行员·飞行器·运营企业·培训机构合规资质
4. **飞行器服务** — 购买·维修·保养·检测·保险咨询对接
5. **低空科普** — 知识·安全常识·产业科普·视频图文
6. **意见反馈** — 意见建议·投诉举报·及时响应

### 1.3 功能清单
- **搜索**：搜索服务项目
- **服务分类卡片**：6 大模块分类卡片，含图标、描述、功能标签
- **热门服务**：6 个热门服务卡片，含评分、价格、标签
- **快捷入口**：发布服务、发布需求、服务评价

### 1.4 交互要点
- 点击「发布服务」→ 跳转 service-publish
- 点击「发布需求」→ 跳转 demand-publish
- 点击「服务评价」→ 跳转 service-review
- 搜索框实时过滤
- 导航栏跳转其他门户页面
