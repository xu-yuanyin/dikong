# 备案飞行器

## 📋 业务与功能

### 1.1 核心目标
提供飞行器在线备案功能，飞手和企业可提交飞行器信息进行备案登记。

### 1.2 功能清单
- **备案表单**：飞行器型号、制造商、序列号、飞行器类型、最大起飞重量、用途
- **材料上传**：上传飞行器相关证明文件
- **提交备案**：提交备案申请等待审核
- **备案查询**：查看已备案飞行器状态

### 1.3 交互要点
- 填写表单 → 提交备案 → 提示提交成功
- 上传材料 → 文件上传成功提示
