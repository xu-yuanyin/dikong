# 服务分类详情

## 📋 业务与功能

### 1.1 核心目标
门户服务分类详情页，展示某个服务模块（如低空旅游、飞行培训等）的详细说明、服务内容、服务流程和安全须知。

### 1.2 功能清单
- **面包屑**：首页 > 服务大厅 > 分类名称
- **返回按钮**：返回服务大厅
- **字号调节**：小/中/大
- **分类信息**：图标、名称、描述
- **正文内容**：服务概述、服务内容、服务流程、安全须知
- **热门服务项目**：该分类下的服务卡片列表，点击跳转 service-detail

### 1.3 交互要点
- 返回 → service-list
- 热门服务卡片 → service-detail
- 字号切换实时生效
