# 本地动态

## 📋 业务与功能

### 1.1 核心目标
展示本地低空飞行实时动态信息，包括飞行活动、空域变化、重要通知等。

### 1.2 功能清单
- **动态列表**：展示本地飞行相关动态信息
- **分类筛选**：按动态类型筛选
- **动态详情**：点击查看详细信息

### 1.3 交互要点
- 点击动态条目 → 查看动态详情
- 切换分类 → 筛选对应类型动态
