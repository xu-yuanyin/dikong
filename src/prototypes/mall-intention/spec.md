# 提交采购意向

## 📋 业务与功能

### 1.1 核心目标
为用户提供低空产品/服务采购意向提交功能，便于商户了解需求并对接。

### 1.2 功能清单
- **采购意向表单**：产品类型、数量、预算、联系方式、需求描述
- **意向提交**：提交采购意向
- **历史意向**：查看已提交的采购意向

### 1.3 交互要点
- 填写表单 → 提交意向 → 提示提交成功
- 查看历史意向列表
