# 空域地图

## 📋 业务与功能

### 1.1 核心目标
展示本地低空空域划分信息，包括禁飞区、限飞区、可飞区域等，为飞行计划提供空域参考。

### 1.2 功能清单
- **空域地图展示**：可视化展示空域划分
- **空域类型筛选**：按类型查看不同空域
- **空域详情**：点击空域查看详细信息

### 1.3 交互要点
- 点击空域区域 → 展示空域详情
- 切换筛选条件 → 地图显示对应空域
