# 我的飞行需求

## 📋 业务与功能

### 1.1 核心目标
用户个人中心-我的飞行需求管理，查看已提交的服务需求列表及处理状态。

### 1.2 功能清单
- **需求列表**：展示用户提交的所有服务需求
- **需求状态**：待处理、处理中、已完成
- **需求详情**：查看需求详细信息
- **新增需求**：跳转提交服务需求页

### 1.3 交互要点
- 点击需求 → 查看需求详情
- 点击「提交需求」→ 跳转服务需求页
