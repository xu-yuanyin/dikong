# 规范标准后台管理

## 📋 业务与功能

### 1.1 核心目标
后台管理端的规范标准管理页面，支持规范标准的全生命周期管理（草稿→发布→撤回）。

### 1.2 功能清单
- **搜索筛选**：标准名称/编号搜索、类型筛选、效力状态筛选、发布状态筛选、查询/重置按钮
- **数据列表**：序号、标准名称、标准编号、类型、发布机构、效力状态、发布状态、发布日期、实施日期
- **操作按钮（按发布状态区分）**：
  - 草稿：查看、编辑、发布、删除
  - 已发布：查看、撤回
- **新增标准**：弹窗表单（名称、编号、类型、效力状态、发布机构、发布日期、实施日期、摘要、正文、附件上传），底部按钮（取消/保存草稿/立即发布）
- **编辑标准**：弹窗表单，字段与新增弹窗完全一致（名称、编号、类型、效力状态、发布机构、发布日期、实施日期、摘要、正文、附件上传），底部按钮（取消/预览/保存）
- **查看标准**：详情弹窗，展示完整信息
- **操作栏**：icon 按钮 + Tooltip 悬停提示

### 1.3 交互要点
- 点击「查看」→ 打开查看弹窗
- 点击「发布/删除/撤回」→ 确认弹窗
- 草稿状态可编辑、发布、删除
- 已发布状态仅可查看和撤回

### 1.4 状态说明
- **效力状态**：现行有效(绿)、已废止(红)、即将实施(蓝)、待生效(蓝)
- **发布状态**：已发布(绿)、草稿(橙)
