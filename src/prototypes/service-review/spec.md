# 服务评价

## 📋 业务与功能

### 1.1 核心目标
门户低空便民服务的评价页面，展示各模块服务评价，支持用户提交评价。

### 1.2 功能清单
- **评分统计**：平均分 4.7、1286 条评价、评分分布柱状图
- **各模块评分**：低空旅游/飞行培训/资质查询/飞行器服务/低空科普/意见反馈 6 模块独立评分
- **评价列表**：8 条评价，含用户头像、服务项目、模块标签、星级、内容
- **排序**：最新/最高评分/最低评分
- **写评价弹窗**：选择服务项目 + 星级 + 评价内容

### 1.3 交互要点
- 返回 → service-show
- 写评价 → 弹窗 → 提交成功
