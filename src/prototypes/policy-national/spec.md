# 国家政策

## 📋 业务与功能

### 1.1 核心目标
展示国家层面低空相关政策法规信息，支持分类浏览和搜索。

### 1.2 功能清单
- **Hero Banner 检索区**：图标 + 标题 + 副标题 + 大搜索框（maxWidth 480, height 44, size large），蓝色渐变背景
- **Tab 导航**：国家政策 / 本地政策 / 政策解读，切换跳转
- **药丸式筛选**：全部 / 现行有效 / 已修订 / 已废止，选中态蓝色填充
- **政策列表**：卡片式展示，含政策类型标签、效力状态标签、标题、摘要、日期、发布单位、下载链接
- **搜索功能**：支持政策名称和发布单位搜索
- **空状态**：无匹配结果时显示提示
- **分页**

### 1.3 交互要点
- 点击政策条目 → 查看政策详情
- 切换效力状态筛选 → 筛选对应状态政策
- 搜索 → 按关键词筛选
- Tab 切换 → 跳转对应页面
