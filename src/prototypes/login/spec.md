# 登录/注册

## 📋 业务与功能

### 1.1 核心目标
提供用户登录和多角色注册认证功能，支持 6 种角色（个人用户、飞手、企业用户、飞行服务商、商户、政府部门）的分步注册，注册完成后跳转登录。

### 1.2 功能清单
- **登录表单**：用户名/手机号、密码、记住我、忘记密码
- **Tab切换**：登录/注册模式切换
- **第三方登录**：微信、支付宝快捷登录入口

**注册流程（分步引导式）**：
- **Step 1 角色选择**：6 张卡片式角色选择（3×2 网格），选中高亮
- **Step 2 基础信息**：手机号 + 验证码（含 60s 倒计时）、密码、确认密码
- **Step 3 认证信息**（根据角色动态变化）：
  - **个人用户**：姓名、身份证号
  - **飞手**：姓名、身份证号、驾驶证编号、驾驶等级（多选）
  - **企业用户**：企业名称、统一社会信用代码、联系人、联系电话
  - **飞行服务商**：企业基础信息 + 服务类型（多选）、服务区域
  - **商户**：企业基础信息 + 主营类目（多选）、经营地址
  - **政府部门**：单位名称、统一社会信用代码、机构类型、联系人、联系电话
- **注册完成**：成功提示 + 审核说明 + 前往登录按钮

### 1.3 交互要点
- 登录成功 → 跳转个人中心
- 注册 Tab 内分步引导：角色选择 → 基础信息 → 认证信息 → 完成
- 注册完成后可点击「前往登录」切回登录 Tab
- 切换到注册 Tab 时重置步骤
- 右上角「重新选择角色」可回到 Step 1
- 点击首页 → 跳转首页

## 🎨 布局与结构

### 3.1 整体布局
- **布局模式**：左右双栏（品牌区 55% + 内容区 45%）
- **品牌区**：深色渐变背景，固定展示
- **内容区**：白色背景，支持纵向滚动

### 3.2 响应式适配
- **桌面端**：左右双栏
- **移动端**：仅显示内容区
