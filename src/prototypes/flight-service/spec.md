# 低空飞行服务

## 📋 业务与功能

### 1.1 核心目标
为个人及企业用户提供飞行计划在线填报、空域查询、飞行许可办理、航线规划、起降点预约、资质办理等全流程服务，实现"足不出户、一键办理"。

### 1.2 功能清单
- **飞行计划填报**：在线填报、材料上传、提交审核、进度查询、批量申报
- **空域信息查询**：空域划设、航路航线、禁飞区、限飞区、临时管制
- **飞行许可办理**：在线申请、材料提交、审批进度、结果反馈
- **航线规划**：自动规划、风险规避、最优路线推荐
- **起降点服务**：位置查询、设施信息、在线预约、费用查询
- **资质办理**：飞行员资质、飞行器备案、运营许可

### 1.3 交互要点
- 服务卡片：点击进入对应服务详情
- 表单提交：分步引导、实时校验、进度保存
- 地图交互：缩放、标注、路线规划
- 状态追踪：实时更新、消息通知
