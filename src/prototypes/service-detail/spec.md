# 服务详情

## 📋 业务与功能

### 1.1 核心目标
门户热门服务详情页，展示某个具体服务项目的完整信息，参考政策详情页设计。

### 1.2 功能清单
- **面包屑**：首页 > 服务概览 > 分类 > 服务名称
- **返回按钮**：返回分类详情
- **字号调节**：小/中/大
- **服务信息**：名称、分类标签、热门标签、价格、时长、区域、评分
- **服务摘要**：高亮摘要区
- **正文内容**：服务介绍、飞行路线、服务包含、配套服务、预订须知、安全保障
- **右侧栏**：立即预约/收藏按钮、服务商信息、温馨提示

### 1.3 交互要点
- 返回 → service-category-detail
- 预约按钮 → 成功提示
- 字号切换实时生效
