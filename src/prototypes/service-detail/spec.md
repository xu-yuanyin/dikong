# 服务详情

## 📋 业务与功能

### 1.1 核心目标
门户热门服务详情页，展示某个具体服务项目的完整信息，参考政策详情页设计。

### 1.2 功能清单
- **面包屑**：首页 > 服务大厅 > 分类 > 服务名称
- **返回按钮**：返回分类详情
- **字号调节**：小/中/大
- **服务信息**：名称、分类标签、热门标签、价格、时长、区域、评分
- **服务摘要**：高亮摘要区
- **正文内容**：服务介绍、飞行路线、服务包含、配套服务、预订须知、安全保障
- **右侧栏**：立即预约/收藏按钮、服务商信息、温馨提示
- **用户评价**：
  - 评分概览：综合评分 + 星级分布柱状图
  - 发表评价：星级打分 + 文字评价（500字限制）+ 提交按钮
  - 评价列表：用户头像、昵称、星级、日期、评价内容、服务商回复、点赞互动

### 1.3 交互要点
- 返回 → service-category-detail
- 预约按钮 → 成功提示
- 字号切换实时生效
- 提交评价 → 评价列表顶部新增该条评价 + 成功提示
- 点赞/取消点赞 → 点赞数实时变化
