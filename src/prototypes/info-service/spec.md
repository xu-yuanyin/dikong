# 低空信息服务

## 📋 业务与功能

### 1.1 核心目标
汇聚国家、省、市低空领域政策、法规、标准及权威解读，提供低空气象服务、通知公告、行业资讯、安全知识等信息服务。

### 1.2 功能清单
- **政策法规**：政策文件、法规标准、权威解读
- **气象服务**：实时气象、精准预报、灾害预警
- **通知公告**：空域管制、禁飞调整、飞行限制
- **行业资讯**：新闻动态、产业资讯、技术前沿
- **安全知识**：飞行安全、风险提示、操作规范
