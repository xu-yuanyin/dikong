# 通知公告详情

## 📋 业务与功能

### 1.1 核心目标
展示通知公告的完整详情内容，包括正文、安全提示、紧急联系方式等。

### 1.2 功能清单
- **面包屑导航**：资讯公告 > 通知公告 > 公告标题
- **返回按钮**：返回通知公告列表（notice tab）
- **公告正文**：标题、类型标签、置顶标识、发布信息、正文内容
- **安全提示**：气象预警等安全相关提示
- **紧急联系方式**：应急联系电话

### 1.3 交互要点
- 点击面包屑「资讯公告」→ 跳转新闻列表
- 点击面包屑「通知公告」→ 跳转资讯公告 notice tab
- 点击「返回」→ 跳转资讯公告 notice tab

```

```
