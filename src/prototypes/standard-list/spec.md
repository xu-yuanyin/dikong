# 规范标准

## 📋 业务与功能

### 1.1 核心目标
门户政策法规模块下的规范标准列表页，展示低空领域相关的国家标准、行业标准、地方标准和技术规范，支持搜索筛选和分类浏览。

### 1.2 功能清单
- **搜索**：关键词搜索规范名称
- **分类筛选**：按标准类型（国家标准/行业标准/地方标准/技术规范）筛选
- **数据列表**：卡片式展示，含标准名称、标准编号、发布机构、发布日期、实施日期、状态标签
- **点击跳转**：点击卡片跳转至规范标准详情页

### 1.3 交互要点
- 点击卡片 → 跳转 standard-detail 详情页
- 搜索框实时过滤
- 分类标签切换筛选
- 顶部导航栏各模块跳转
