# 低空服务模块 — 核心业务与流程总览

> **编制日期**：2026 年 5 月 12 日  
> **编制单位**：郑州元引信息科技有限公司

---

## 一、模块简介

「低空服务」是一个**低空作业服务集市**，让有飞行能力的服务商和飞手在平台上发布服务，让有需求的政府、企业和个人来预约或发布需求，平台撮合双方完成交易。

---

## 二、谁在用？各自能做什么？

### 供给方（卖服务）

| 角色 | 能发布的服务类别 |
|:---|:---|
| **飞行服务商**（企业） | 行业应用、航拍影像、飞行培训、低空旅游、飞行器服务、其它定制服务 |
| **飞手**（个人） | 航拍影像、飞行培训（私教）、其它定制服务 |

### 需求方（买服务）

| 角色 | 典型使用场景 |
|:---|:---|
| **政府部门** | 发布农业灌溉、环保巡查等政务级服务需求 |
| **企业用户** | 预约航拍测绘、电力巡检等企业级服务 |
| **个人用户** | 预约婚礼跟拍、报名飞行培训等个人消费 |

## 三、两条核心业务线

### 业务线 1：直接预约（需求方主动找服务）

```
需求方逛服务大厅 → 找到合适的服务 → 点击预约
    ↓
供给方「收到的工单」中出现新单
    ↓
供给方联系客户 → 线下执行作业 → 提交交付
    ↓
需求方确认完成 → 评价打分
```

**工单状态**：`待联系` → `进行中` → `待确认` → `已完成`

### 业务线 2：发布需求（需求方等人来接单）

```
需求方发布一条服务需求（如：急需 3 名飞手做楼盘航拍）
    ↓
多个供给方看到需求 → 响应接单
    ↓
需求方挑选合适的供给方 → 线下对接合作
    ↓
需求方将需求标记为「已解决」
```

**需求状态**：`进行中` → `已解决` / `已关闭`

## 四、发布规则

- **免审核上架**：供给方发布服务后直接公开展示，无需等待审核。
- **违规处理**：后台管理员日常巡查，发现违规服务一键「强制下线」。
  - 供给方可在前台删除违规记录，如有疑问致电客服：**400-123-4567**。
  - 确认合规后，通过统一的「发布服务项目」入口重新发布即可。
  - 后台管理端保留强制下线记录，**不可删除**，作为审计留痕。

**服务的三种状态**：

| 状态 | 说明 |
|:---|:---|
| 正常上架 | 服务展示中，可被预约 |
| 自行下架 | 供给方主动暂停，可随时重新上架 |
| 平台强制下线 | 后台管理员执行，供给方只能删除后重发 |
