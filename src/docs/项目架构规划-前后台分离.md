# 项目架构规划 - 前后台分离

## 一、项目概述

区域低空公共服务管理体系，面向政府部门、企业、飞手、公众提供一站式低空服务。

## 二、架构划分

### 前台展示（面向公众用户）

面向企业、飞手、公众用户，提供服务申请、信息查询、业务办理等功能。

## 三、目录结构规划

```
src/
├── prototypes/           # 前台原型页面
│   ├── home/            # PC端门户首页
│   ├── mobile-*/        # 移动端页面
│   ├── flight-*/        # 飞行服务相关
│   ├── info-*/          # 信息服务相关
│   ├── emergency-*/     # 应急服务相关
│   └── public-*/        # 便民服务相关
│
├── admin/               # 后台管理页面（待开发）
│   ├── login/           # 登录页
│   ├── dashboard/       # 首页仪表盘
│   ├── system/          # 系统管理
│   │   ├── user/        # 用户管理
│   │   ├── role/        # 角色管理
│   │   └── log/         # 操作日志
│   ├── flight/          # 飞行服务管理
│   │   ├── plan/        # 飞行计划审批
│   │   ├── airspace/    # 空域管理
│   │   └── permit/      # 许可证管理
│   ├── emergency/       # 应急服务管理
│   │   ├── alarm/       # 报警处理
│   │   ├── rescue/      # 救援调度
│   │   └── warning/     # 预警管理
│   ├── info/            # 信息服务管理
│   │   ├── policy/      # 政策发布
│   │   ├── notice/      # 公告管理
│   │   └── news/        # 资讯管理
│   ├── public/          # 便民服务管理
│   │   ├── tour/        # 旅游线路管理
│   │   ├── training/    # 培训机构管理
│   │   └── feedback/    # 反馈处理
│   └── statistics/      # 数据统计
│       ├── flight/      # 飞行统计
│       ├── airspace/    # 空域统计
│       └── user/        # 用户统计
│
├── components/          # 公共组件
├── common/              # 公共类型和工具
├── themes/              # 主题配置
└── database/            # 数据表
```

## 四、用户角色权限

| 角色 | 前台权限 | 后台权限 |
|------|----------|----------|
| 公众用户 | 浏览信息、申请服务 | 无 |
| 企业用户 | 浏览信息、申请服务、业务管理 | 无 |
| 飞手用户 | 浏览信息、申请服务、资质管理 | 无 |
| 审批人员 | 无 | 飞行计划审批、许可证审批 |
| 应急人员 | 无 | 报警处理、救援调度 |
| 内容管理员 | 无 | 政策发布、公告管理 |
| 系统管理员 | 全部 | 全部 |
