## 一、项目概述

### 1.1 项目背景

以便民利企、普惠高效为核心，建设区域低空公共服务管理体系。平台基于网页端+移动端，为政府部门、企业、飞手、公众提供全场景、一站式、便捷化低空公共服务，涵盖资讯公告、政策法规、低空服务、低空商城、飞行服务、个人中心、后台管理七大功能板块。

### 1.2 项目目标

- 为社会公众提供低空资讯、政策查询、服务预约、商品采购等便民服务
- 为飞行从业者提供飞行器备案、飞行计划申报、空域查询、资质管理等专业服务
- 为监管部门提供飞行主体审批、飞行器审批、飞行计划审批、空域管理等监管能力
- 为服务商户提供商品发布、订单管理、服务上架等运营能力

### 1.3 系统架构

系统采用前后端分离架构，分为**门户端**（面向公众和从业者）和**后台管理端**（面向管理员和监管部门），共设计 53 个原型页面。

## 二、角色与权限模型

### 2.1 系统角色

| 角色编码 | 角色名称 | 角色说明 | 注册认证信息 |
|---------|---------|---------|------------|
| `personal` | 个人用户 | 浏览资讯、使用基础服务 | 姓名、手机号、身份证号 |
| `pilot` | 飞手 | 申请飞行计划、参与活动 | 姓名、手机号、身份证号、飞行器类型、执照编号、飞行时长 |
| `enterprise` | 企业用户 | 业务对接与信息管理 | 企业名称、统一社会信用代码、联系人、联系电话 |
| `provider` | 飞行服务商 | 提供低空飞行专业服务 | 企业名称、统一社会信用代码、服务类型、联系人、联系电话 |
| `merchant` | 商户 | 入驻商城销售产品 | 店铺名称、经营范围、联系人、联系电话 |
| `government` | 政府部门 | 低空管理与审批监管 | 单位名称、统一社会信用代码、机构类型、联系人、联系电话 |
| `admin` | 系统管理员 | 后台系统管理 | 管理员账号（后台分配） |

### 2.2 注册认证流程

1. **选择角色**：6 种角色卡片选择
2. **填写基本信息**：根据角色动态展示对应表单
3. **填写认证信息**：上传证件、填写资质信息
4. **提交审核**：后台管理员审核通过后激活账号

## 五、全局交互规范

### 5.1 导航规范

| 区域 | 导航方式 |
|------|---------|
| 门户页面 | 顶部渐变色导航栏（蓝/紫/青色渐变） |
| 个人中心 | 左侧固定菜单（含分组标题）+ 面包屑 |
| 后台管理 | 顶部深色导航栏（#001529）+ 面包屑 |
| 飞行服务 | 青色渐变头部 + 无 Tab 直接展示 |

### 5.2 页面跳转

- 所有页面跳转使用 `window.location.href = '/prototypes/' + key`
- 详情页面包屑支持返回列表
- 后台管理顶部导航直接跳转对应管理页面

### 5.3 详情页规范

- 左侧：面包屑 → 返回按钮 + 字号控制 → 标签 → 标题 → 元信息 → 内容
- 右侧：操作按钮（预约/采购/投标）+ 信息卡片（供应商/联系方式/服务保障）
- 字号控制：小(13px) / 中(15px) / 大(17px)

### 5.4 表单规范

- 必填项标记红色星号
- 提交后显示 `message.success` 提示
- 后台 CRUD 统一使用 Modal 弹窗

### 5.5 状态标签

| 状态 | 颜色 | 适用场景 |
|------|------|---------|
| 待审批/待审核/待使用 | orange | 审批、预约 |
| 已通过/已确认/已完成/在售/可用 | green | 审批、订单、商品 |
| 已驳回/已取消/禁飞 | red/default | 审批、预约、空域 |
| 审核中/进行中/执行中 | blue/processing | 审批、飞行计划 |
| 已下架/已关闭 | default | 商品、需求 |
